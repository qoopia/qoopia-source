Подключите свою память.

Память остаётся на выбранном компьютере или сервере. Каждый клиент получает отдельное подключение с отзываемыми правами.

Выпуск поддерживает проверенные сочетания Codex CLI, Claude Code, Claude Desktop и Claude Web из списка ниже. ChatGPT Web и Desktop экспериментальны: вызовы памяти прошли в отдельном прототипе, но проверка завершения настройки не принята. Сохранённая конфигурация сама по себе не подтверждает подключение.

Начните со своего пространства

  1. Откройте Qoopia. Проверьте название пространства и машину в боковой панели. Если вы уже используете сервер, оставьте его выбранным.
  2. Откройте Подключения. Выберите клиент и права: Только чтение или Чтение и добавление.
  3. Для клиентов, которые обращаются из облака, включите Внешнюю связь. Подтвердите аккаунт Qoopia по почте или через Google и нажмите Продолжить настройку. Домен, настройка роутера и аккаунт провайдера туннеля не нужны.
  4. Подготовьте подключение, затем выполните шаги для клиента ниже. Qoopia покажет точный адрес. На странице OAuth проверьте пространство, клиент и права перед подтверждением.
  5. Нажмите Получить запрос проверки, выполните его в выбранном клиенте и проверьте статус в Qoopia. Запрос действует десять минут; при необходимости получите новый.

Codex

На компьютере с этой установкой нажмите Добавить в клиент на этом компьютере. Для другого компьютера скачайте файл настройки и откройте его там в Qoopia. Подтвердите вход для появившейся записи Qoopia в Codex. CLI поддерживает команду codex mcp login NAME; имя записи возвращается в плане и статусе настройки. Выполните запрос проверки в Codex. Локальная установка автоматически использует локальный адрес.

Claude Code

Добавьте запись той же кнопкой Qoopia или файлом настройки. Откройте Claude Code, выполните /mcp, выберите подключение Qoopia и подтвердите доступ. Затем выполните запрос проверки. Остальные подключения MCP и ключи моделей сохраняются.

ChatGPT Web — экспериментально

Откройте Плагины → + → Новый плагин. Выберите OAuth и вставьте подготовленный адрес. При необходимости включите режим разработчика в Настройки → Безопасность и вход. Проверьте права, подтвердите доступ в Qoopia, включите плагин в беседе и выполните запрос проверки. Доступность зависит от тарифа и политики рабочего пространства. Этот путь настройки не принят для текущего выпуска. Если клиент блокирует проверку, оставьте подключение неподтверждённым и остановите эту попытку проверки.

ChatGPT Desktop — экспериментально

В проверенном приложении macOS прошли чтение, добавление и защита от дублей в настоящем чате ChatGPT. Откройте New chat → Chat и выберите подключённое приложение там. Проверенная кнопка Try now создавала задачу Codex даже при заголовке ChatGPT слева — это отдельный результат клиента. Полная проверка завершения настройки и входа аккаунта на текущем пакете не принята. Заблокированную проверку нельзя повторять через другой путь.

Claude Web

Откройте Настройка → Коннекторы → + → Добавить свой коннектор. Вставьте адрес, добавьте коннектор, нажмите Подключить и подтвердите OAuth. Включите его в беседе и выполните запрос проверки. На Free доступен один собственный коннектор; в Team и Enterprise его добавляет владелец организации.

Claude Desktop

На Mac нажмите Добавить в клиент на этом компьютере, затем Открыть подтверждение. Для памяти на другой машине скачайте файл настройки и откройте его в Qoopia на Mac. Проверьте пространство и права в браузере. Вернитесь в Qoopia и проверьте статус, перезапустите Claude Desktop и выполните запрос проверки в новой беседе. Локальный адаптер хранит OAuth отдельно от конфигурации Claude и запускает выбранную установленную версию Qoopia после обновления. В Linux можно подготовить файл настройки для Mac. Claude Desktop 1.52386.3 на macOS прошёл реальные вызовы памяти, обновление токена, импорт файла и чтение после полной перезагрузки.
Отдельный способ удалённого подключения находится в Настройка → Коннекторы. Ему нужен доступный внешний адрес: запросы идут из облака Anthropic.

Официальная инструкция локальных расширений

Продолжение после сбоя

Подготовленные подключения сохраняются в пространстве. Снова откройте Подключения и проверьте статус. Спящая, выключенная или потерявшая сеть машина не отвечает, но её память не потеряна. Служба переподключается после пробуждения и восстановления сети. Прерванную запись повторяют только с тем же ключом идемпотентности и неизменными данными.

«Вызов клиента подтверждён» — отметка последнего успешного вызова. Состояние внешней связи показывается отдельно. Если вход истёк, начните вход заново, сохранив подготовленное подключение. Для клиента на другом компьютере используйте внешний адрес сервера.

Управление доступом

Чтение и добавление разрешает читать память и создавать новые записи. Изменение и удаление существующих заметок в эти права не входят. Такие инструменты недоступны этому подключению.

Нажмите Отозвать доступ для одного клиента или приостановите внешнюю связь всей установки. Отзыв не удаляет память. Cloudflare обрабатывает разрешённый трафик в пути и завершает HTTPS; сквозное шифрование не заявляется. Сервис аккаунтов хранит данные аккаунтов и устройств, а не копию базы памяти.

MCP предоставляет инструменты чтения и разрешённой записи. Он не сохраняет всю переписку автоматически. Вход в подписку для фоновой модели настраивается отдельно в Настройках модели памяти.

Проверенные сочетания клиентов

Результаты от 12 сентября 2026 года получены с действующими подписками ChatGPT Pro и Claude Max. Они не подтверждают другие тарифы, ОС и версии клиентов. Каждый пункт — отдельная проверка клиента.

  • Codex CLI 0.153.3, Linux x64: прошли OAuth, проверка, чтение, добавление и защита от дубликатов; чтение после обновления, сна и перезагрузки.
  • Claude Code 2.1.224, Linux x64: прошли та же последовательность вызовов памяти и чтение после перезагрузки.
  • Claude Desktop 1.52386.3, macOS Apple Silicon: прошли локальный адаптер, OAuth, вызовы памяти, обновление естественно истёкшего токена и импорт файла; чтение после обрыва сети и перезагрузки.
  • Claude Web: прошли удалённый OAuth, проверка, чтение, добавление и защита от дубликатов с памятью чистого Mac.
  • ChatGPT Web: OAuth, чтение, добавление и защита от дубликатов прошли в изолированном синтетическом прототипе. Клиент заблокировал вызов проверки; полная приёмка этой поверхности не завершена.
  • ChatGPT Desktop: ручные чтение, добавление и защита от дублей прошли в чате ChatGPT на macOS. Независимая проверка тестовой базы подтвердила одну новую запись. Эти результаты прототипа не подтверждают полный путь настройки текущего выпуска.

Сон и пробуждение физического Mac прошли с подписанной локальной установкой V14: сохранились процесс, запись и настройки на момент перед сном. Это проверка локального восстановления, отдельная от клиентов и сети. Гостевая VM отклонила сон; обрыв сети и перезагрузка проверены отдельно.

Установка и локальные файлы

Сборка предназначена для macOS Apple Silicon и Linux x64. В Linux распакуйте архив, откройте его папку и запустите Open Qoopia. Отдельный файл open-qoopia.sh предназначен для запуска из терминала: некоторые файловые менеджеры открывают shell-скрипты в редакторе. Оба пакета подписаны издателем; пакет macOS прошёл Apple notarization. Установка на чистых системах и обновление проверены. В область приёмки выпуска входят только сочетания клиентов, отмеченные выше как поддерживаемые. На macOS откройте файл .qoopia-connection в Qoopia и проверьте адрес перед добавлением. В Linux CLI: qoopia client-link --file /абсолютный/путь.qoopia-connection, затем --commit --approve PLAN_DIGEST из показанного плана. Редактировать конфиги не нужно. Файл настройки содержит адрес и права, а не токен.

Отдельная инструкция connections-agent.md в пакете описывает команды для агента и стабильные коды состояния.

Официальные инструкции клиентов проверены 12 сентября 2026 года. Приёмка реальных аккаунтов, ОС и клиентов учитывается отдельно.
