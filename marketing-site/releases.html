Qoopia releases

Qoopia V1 launched on 14 September 2026. Signed installers are available for macOS Apple Silicon and Linux x64. Qoopia V1 source is public under MIT.

Latest changes and previous versions: Release history ↗

Version 5.0.9 — 21 September 2026

A consistent Graphite identity

Theme-aware favicons, the approved logo and consistent typography across the dashboard, account pages and new emails.

Also included: changes since 5.0.5

  • Automatic memory resumes without dropping the first batch after manual mode. Manual-period content stays excluded.
  • Mac upgrades from older signed installations open correctly and preserve existing data and connections.
  • Overview opens first. Compact navigation and persistent chat keep your agent within reach on every dashboard page.
  • Email confirmation opens the connected dashboard directly in the iPhone app. Native iOS uses a separate TestFlight build and Apple review.

Version 5.0.4 — 17 September 2026

Reliable Telegram agents

  • Queued messages resume after subscription sign-in and survive a restart.
  • Stop cancels the active task and queued messages.
  • Claude conversation history retains both your messages and the agent’s replies.
  • Subscription sign-in and permission recovery are available directly in the dashboard.

Memory, connections and Bridges

  • A consistent interface across desktop, browser and embedded access to one selected environment.
  • A Connections page for MCP clients, native integrations and explicit authorization.
  • Native Claude Code and Codex session context capture and restoration.
  • Bridges for invited, version-specific sharing between separate installations.
  • Clear separation between owner identity, model subscription and client-agent access.

Current packages

Supported targets are macOS Apple Silicon and Linux x64 with glibc 2.34+. Qoopia does not claim Windows, Intel Mac or universal Linux support.

Version, filenames, sizes and checksums are held in one machine-readable release manifest. Downloads and checksums are published in the official Qoopia download channel.

Current limitations

  • Cloud browser clients need reachable HTTPS or a supported tunnel.
  • There is no published Qoopia entry in the ChatGPT plugin directory.
  • Generic browser MCP does not capture a full transcript.
  • Steward assignment does not launch an AI runtime.
