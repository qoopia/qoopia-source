Qoopia V1.

Public V1 release. Signed installers are available for macOS Apple Silicon and Linux x64. Qoopia V1 source is public under MIT.

Memory, connections and Bridges

  • A consistent interface across desktop, browser and embedded access to one selected environment.
  • A Connections page for MCP clients, native integrations and explicit authorization.
  • Native Claude Code and Codex session context capture and restoration.
  • Bridges for invited, version-specific sharing between separate installations.
  • Clear separation between owner identity, model subscription and client-agent access.

Packages

Supported targets are macOS Apple Silicon and Linux x64 with glibc 2.34+. This release does not claim Windows, Intel Mac or universal Linux support.

Version, filenames, sizes and checksums are held in one machine-readable release manifest. Downloads and checksums are published in the official Qoopia download channel.

Current limitations

  • Cloud browser clients need reachable HTTPS or a supported tunnel; automatic local provisioning is not implemented.
  • There is no published Qoopia entry in the ChatGPT plugin directory.
  • Generic browser MCP does not capture a full transcript.
  • Steward assignment does not launch an AI runtime.
