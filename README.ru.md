# Qoopia

**Память, которой ваши AI-агенты могут пользоваться вместе — под вашим контролем.**

[Сайт](https://qoopia.ai) · [Установка с агентом](https://qoopia.ai/docs#agent-install) · [Скачать](https://github.com/qoopia/qoopia-downloads/releases/latest) · [English](README.md)

Qoopia сохраняет память между сессиями и клиентами. Установите её на свой компьютер или сервер, подключите агентов через MCP и продолжайте общаться с ними в привычных приложениях.

## Что она умеет

- Хранить заметки, файлы и контекст сессий для подключённых агентов.
- Показывать агентов, их заметки и общение AgentComm в дашборде.
- Запускать «Моего Qoopia агента» через Codex или Claude Code с вашей подпиской. Общение — в дашборде или через вашего Telegram-бота.
- Настраивать контролируемые мосты между отдельными средами: вы выбираете, чем делиться и что импортировать.
- Упаковывать одобренный опыт в переиспользуемые скиллы и передавать выбранные материалы между средами.

## Как начать

Если у вас уже есть Codex или Claude Code с доступом к компьютеру, отправьте ему:

```text
Установи Qoopia на этом компьютере по https://qoopia.ai/docs#agent-install.
Полностью прочитай инструкцию, проверь официальный установщик и создай мою
собственную память. Для входов и согласий обращайся ко мне. Подключи выбранный
мной клиент и проверь реальный вызов памяти, прежде чем объявлять успех.
```

Можно также [скачать установщик](https://github.com/qoopia/qoopia-downloads/releases/latest) и пройти включённую инструкцию самостоятельно.

V1 поддерживает **Apple Silicon с macOS 15+** и **Linux x64 с glibc 2.34+**; для Linux нужен `procps`. Windows и Intel Mac в эту поставку не входят. ChatGPT Web/Desktop MCP пока экспериментальны. Управляемый HTTPS работает как ограниченный пилот; полный вход настоящего пользователя для него ещё не квалифицирован. Telegram требует собственного бота и работающего компьютера.

## Ваша память

Память хранится в выбранной вами установке. Регистрация на сайте не даёт доступа к чужой базе. Доступ через MCP и подписка для запуска модели настраиваются отдельно. Мосты не объединяют личные базы автоматически.

Вызовы внешних моделей и браузерные подключения могут передавать разрешённые данные за пределы компьютера. Управляемый HTTPS использует Cloudflare Tunnel: сквозного шифрования через этого посредника нет.
