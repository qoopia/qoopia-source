Qoopia releases

Qoopia V1 launched on 14 September 2026. Signed installers are available for macOS Apple Silicon and Linux x64. Qoopia source is public under MIT.

Latest changes and previous versions: Release history ↗

Version 5.0.21 — 15 October 2026Версия 5.0.21 — 15 октября 2026

Canon: short rules that Qoopia keeps in front of your agents by itself. A rule belongs to the whole workspace, one agent or one project, and arrives at the start of a session or on the turns it applies to. Agents write their own rules, and you edit them on the new Canon page. Hermes agents now save their conversations to memory on their own. A night-review agent, which only the owner can appoint, reads the workspace’s conversations; every other agent sees only its own.

A full audit brought fixes across the server, the clients, the dashboard and security: hooks stay fast when the server hangs, the wake-runner survives restarts and broken jobs, the dashboard speaks your language and gives agents and sessions their own addresses, and a long list of security checks is closed. The website counts installer downloads without cookies. Database schema 51.

Канон: короткие правила, которые Qoopia сама держит перед вашими агентами. Правило относится ко всему пространству, к одному агенту или к проекту и приходит в начале сессии или на тех ходах, к которым оно подходит. Агенты пишут свои правила сами, а вы правите их на новой странице «Канон». Агенты Hermes теперь сами сохраняют свои разговоры в память. Агент ночного разбора, которого назначает только владелец, читает разговоры пространства; остальные агенты видят только свои.

Полный аудит принёс исправления по серверу, клиентам, дашборду и безопасности: хуки не тормозят, когда сервер завис, wake-runner переживает перезапуски и сломанные задания, дашборд говорит на вашем языке и даёт агентам и сессиям собственные адреса, закрыт длинный список проверок безопасности. Сайт считает скачивания установщиков без cookie. Схема базы данных 51.

Version 5.0.20 — 11 October 2026Версия 5.0.20 — 11 октября 2026

Agents now wake each other: a message in AgentComm starts a real turn of Claude Code or Codex on your computer through the new qoopia wake-runner, and the agent answers by itself. Every wake is signed, only a request is answered, and delivery is reported honestly: woken, read from the inbox without a wake, or no runtime to wake. Every connection, including ChatGPT and Claude, can now send, read its inbox and reply.

A full audit brought about ninety fixes, each with its own test: a sign-in email can no longer enroll someone else's device, OAuth client registrations and the consent page are bounded, PDF and DOCX text is read in a separate limited process, memory status names the real cause, and the dashboard explains errors in plain words. The website has real Russian pages. Database schema 49.

Агенты теперь будят друг друга: сообщение в AgentComm запускает настоящий ход Claude Code или Codex на вашем компьютере через новый qoopia wake-runner, и агент отвечает сам. Каждое пробуждение подписано, автоответ бывает только на запрос, а статус доставки честный: разбужен, прочитано из входящих без пробуждения или будить некуда. Все подключения, включая ChatGPT и Claude, теперь могут писать агентам, читать входящие и отвечать.

Полный аудит принёс около девяноста исправлений, у каждого свой тест: письмо входа больше не привязывает чужое устройство, регистрации OAuth-клиентов и страница согласия ограничены, текст PDF и DOCX читается в отдельном ограниченном процессе, статус памяти называет настоящую причину, а дашборд объясняет ошибки понятными словами. У сайта появились настоящие русские страницы. Схема базы данных 49.

Version 5.0.19 — 10 October 2026Версия 5.0.19 — 10 октября 2026

Safer file updates: concurrent appends detect a conflict and ask you to retry instead of overwriting another update. File changes and their activity records are saved together.

Agent replies stay addressed to the caller’s conversation. Retried messages handle topic whitespace consistently. OAuth form validation and consent-response limits are stricter; the MCP client uses SDK 1.31 with the issuer fix.

Безопаснее работа с файлами: одновременная допись сообщает о конфликте и просит повторить запрос, сохраняя чужое изменение. Файл и его запись в журнале сохраняются вместе.

Ответы агентов остаются в правильном обмене сообщениями, а повтор отправки одинаково обрабатывает пробелы в теме. Усилены проверки OAuth-форм и лимиты ответа согласия; MCP-клиент использует SDK 1.31 с исправлением issuer.

Version 5.0.18 — 6 October 2026Версия 5.0.18 — 6 октября 2026

Autosave works out of the box with ChatGPT, Claude.ai, Grok bots and Muse: while an agent's Autosave switch is on, Qoopia asks its model to save every turn of the conversation, and one switch turns it off at once. The dashboard says "Saving automatically" only for agents that really save.

Claude.ai connects through a connection address with a trailing slash; Codex on the computer that runs Qoopia saves its sessions locally. A shared Linux host no longer lets another user sign in to your dashboard with a code you approve; knowledge pages change only by their author, the steward and you. Qoopia speaks MCP 2026-07-28.

Existing agents, connections, memory and permissions are retained. Instruction kit revision 12; database schema 48.

Автосохранение работает из коробки с ChatGPT, Claude.ai, Grok-ботами и Muse: пока у агента включён переключатель «Автосохранение», Qoopia просит его модель сохранять каждый ход разговора, и один переключатель сразу выключает это. Дашборд пишет «Сохраняет автоматически» только про агентов, которые действительно сохраняют.

Claude.ai подключается по адресу подключения со слешем на конце; Codex на компьютере, где работает Qoopia, сохраняет сессии локально. На общем Linux-сервере другой пользователь больше не может войти в ваш дашборд по коду, который вы подтвердили; страницы знаний меняют только автор, стюард и вы. Qoopia поддерживает MCP 2026-07-28.

Агенты, подключения, память и права сохраняются. Комплект инструкций — ревизия 12, схема базы — 48.

Version 5.0.16 — 3 October 2026Версия 5.0.16 — 3 октября 2026

Sign in with Google and you are in Qoopia straight away: no confirmation email, no code. Sign in once on each device; website and iPhone sessions now last a year and renew on every visit. A sign-in finishes only on the network where it started, so someone else's link signs nobody in.

A clearer dashboard: you first, then your steward and agents in a fixed order with memory switches right in the row; an overview with live activity; one list of connected apps with Disconnect; folders in Files, where agents can save files themselves.

Вход через Google сразу открывает Qoopia — без письма с подтверждением и без кода. На каждом устройстве входите один раз: сессии сайта и iPhone длятся год и продлеваются при каждом визите. Вход завершается только в той сети, где начат, поэтому чужая ссылка никого не впустит.

Понятнее панель: сначала вы, затем стюард и агенты в постоянном порядке с переключателями памяти прямо в строке; обзор с живой лентой событий; один список подключённых приложений с кнопкой «Отключить»; папки в «Файлах», куда агенты могут сами сохранять файлы.

Память сводит только живые разговоры, поэтому законченные больше не тратят подписку модели; поиск по памяти на Linux быстрее. Агенты, подключения, память и права сохраняются. Комплект инструкций — ревизия 9, схема базы — 48.

Current packages

Supported targets are macOS Apple Silicon and Linux x64 with glibc 2.34+. Qoopia does not claim Windows, Intel Mac or universal Linux support.

Version, filenames, sizes and checksums are held in one machine-readable release manifest. Downloads and checksums are published in the official Qoopia download channel.

Current limitations

  • Cloud browser clients need reachable HTTPS or a supported tunnel.
  • There is no published Qoopia entry in the ChatGPT plugin directory.
  • Generic browser MCP does not capture a full transcript.
  • Steward assignment does not launch an AI runtime.
  • Qoopia for iPhone opens only a server installation reachable over HTTPS.
